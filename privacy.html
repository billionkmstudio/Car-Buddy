私隱政策

Car Buddy 要用前置鏡頭睇住你嘅樣貌先可以偵測疲倦，所以我哋將「你嘅樣貌去咗邊」講清楚。

最後更新：2026 年 11 月 · 版本 v1.4.0

一句講晒：鏡頭畫面只喺你部手機嘅記憶體入面即時分析，唔會錄影、唔會儲存、唔會上傳。Billion Studio 冇任何伺服器會收到你嘅樣貌。

1. 你嘅樣貌：只喺你部手機入面處理

  • 偵測用嘅 AI（MediaPipe Face Landmarker）係下載到你部手機嘅瀏覽器入面運行，所有分析喺手機本機完成。
  • 鏡頭每一格畫面分析完就即刻丟棄，唔會錄影、唔會影相、唔會截圖、唔會寫入手機儲存空間。
  • 分析之後只剩幾個數字（例如眼睛張開程度、打吹欠程度、頭部角度），用嚟判斷你係咪眼瞓。呢啲數字都只留喺手機記憶體，關閉頁面就消失。
  • 畫面上睇到嘅鏡頭影像只係畫喺你自己嘅螢幕，冇傳送去任何地方。你可以隨時撳主頁「隱藏鏡頭畫面」，偵測照常，只係唔再顯示。

2. 會儲存喺你手機嘅資料

以下資料用瀏覽器嘅本機儲存（localStorage）放喺你自己部手機，唔會傳送俾 Billion Studio：

資料用途點樣刪除
偵測設定（靈敏度、音量、音樂開關等）下次開啟唔使重新設定設定最底「清除所有本機資料」
AI 聊天 API Key 同你揀嘅服務／模型俾 Buddy 開口傾偈主頁清除，或或喺設定清空 API key 欄
駕駛偵測報告（只記錄曾發出警告嘅行程：時間、警告類型、閉眼時間、PERCLOS 峰值）俾你自己事後翻睇報告頁「清除全部記錄」

報告唔包含任何相片或影片，只有時間同數字。最多保留最近 60 程。

3. 會連去外面嘅部分

Car Buddy 係靜態網頁，冇登入、冇帳戶、冇我哋嘅資料庫。但為咗運作，你部手機會向第三方下載或傳送以下內容：

  • 載入偵測程式同模型：由 jsDelivr（程式庫）同 Google Cloud Storage（人臉模型檔）下載。呢個係「下載」，唔會上載你嘅畫面。同所有網站一樣，對方會見到你嘅 IP 位址同瀏覽器資料。
  • 字體：由 Google Fonts 下載。
  • Buddy 聊天（可選）：只有當你自己填咗 API Key 並開啟聊天，系統先會將一小段文字（例如「司機而家好眼瞓」同你講過嘅說話文字）傳去你揀嘅 AI 服務（Groq、Google Gemini、OpenRouter、Mistral 或自訂）。傳送嘅係文字，唔係鏡頭畫面，亦唔係你嘅樣貌。你所用服務點處理呢啲文字，受該服務自己嘅私隱政策規管。
  • 語音輸入（可選）：「同 Buddy 傾偈」同「叫 Buddy」會用手機瀏覽器內置嘅語音辨識。喺 Android Chrome，呢個功能通常會將你嘅聲音交畀 Google 嘅語音服務處理；喺 iPhone 則由 Apple 處理。請留意你部手機同瀏覽器嘅相關私隱設定。唔想用就唔好撳「同 Buddy 傾偈」，亦唔好剔選「語音喚醒」。
  • 語音朗讀：使用手機本身嘅語音引擎，一般唔需要上載。

4. 我哋有冇伺服器儲存你嘅資料？

冇。Car Buddy 冇用戶帳戶、冇雲端資料庫，我哋亦冇任何程式會收集你嘅樣貌、偵測結果、行程記錄或 API Key。

補充：任何網站嘅寄存服務商，通常都會有標準嘅伺服器存取記錄（例如連線時間、IP 位址、瀏覽器種類）。呢啲係寄存層面嘅一般記錄，同你嘅樣貌或偵測內容無關。

5. 鏡頭權限

瀏覽器會喺你撳「開始偵測」時先問你可唔可以用鏡頭。你隨時可以：

  • 撳「停用偵測」，鏡頭即刻關閉；
  • 喺手機瀏覽器嘅網站設定收回鏡頭權限。

6. 關於 API Key 嘅安全

  • Key 只存喺你部手機，只會傳送去你自己揀嘅 AI 服務。
  • 請用免費或有用量上限嘅 Key，唔好同人分享你部手機嘅瀏覽器資料。
  • 如果懷疑外洩，去該服務嘅後台刪除舊 Key 再建立新嘅。

7. 兒童

Car Buddy 係俾司機使用，並非為兒童而設。

8. 政策更新

功能有重大改變（例如日後加入雲端功能）時，我哋會更新呢頁並提升版本號；任何會上傳樣貌嘅功能，一定會先要你明確同意。
