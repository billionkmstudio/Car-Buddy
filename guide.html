0. 先睇：安全提示

Car Buddy 只係輔助提示，唔可以代替休息。一收到警告，就要揀安全地方停車。唔好用佢嚟「撐」長途駕駛。

行駛途中唔好望住手機或撳掣。設定、校準同睇報告，請喺停好車時做。

1. 開始用

  1. 用手機 Chrome（Android）或 Safari（iPhone）打開 Car Buddy 網址。
  2. 撳「開始偵測」，瀏覽器問鏡頭權限時揀「允許」。
  3. 首次載入 AI 模型需要網絡，大約幾秒到十幾秒。
  4. 坐好、面向鏡頭，睇到畫面有你，就等佢自動校準；之後想重做就撳「重新校準」。
  5. 校準完成後，撳「隱藏鏡頭畫面」（可選），然後將手機固定好就可以出發。
  6. 完結行程撳「停用偵測」。

建議第一次先喺停好嘅車入面撳「測試警報」，確認聲音夠大、你聽得到。

2. 校準（最重要）

每個人眼睛大細、坐姿都唔同。校準會記低你正常清醒時嘅眼睛張開程度同頭部角度，之後所有判斷都係同「你自己嘅基準」比較。

  • 校準時請望住前方路面嘅方向、眼睛自然張開，唔好特登瞪大眼。
  • 光線要夠，避免強烈背光（例如面後係大窗）。
  • 換咗人駕駛、換咗手機位置、戴／除太陽眼鏡，都要重新校準。
  • 太陽眼鏡深色會令眼睛偵測失準；一般透明眼鏡通常冇問題。

3. 隱藏鏡頭畫面

校準成功後，你唔使再望住自己個樣。撳「隱藏鏡頭畫面」，畫面收埋，騰出空間顯示狀態同掣。

  • 隱藏只係唔顯示影像，偵測同鏡頭照常運作，警報、Buddy 同音樂都唔受影響。
  • 想重新睇畫面（例如檢查自己有冇企出畫面），撳「顯示鏡頭畫面」。
  • 設定入面有「校準完成後自動隱藏鏡頭畫面」，剔選後唔使每次手動撳。

4. 警告分幾級

情況系統反應
輕微：眨眼變慢、打吹欠畫面提示，並記入行程
中度：閉眼比例（PERCLOS）升高提醒聲，Buddy 可能主動同你傾偈
危險：長時間閉眼、頭部低垂、閉眼比例太高大聲警報＋震動（Android）＋語音「喂！醒呀，醒呀！…」，並記入報告

PERCLOS = 最近 60 秒內，眼睛接近閉合所佔嘅時間比例，係業界常用嘅疲倦指標。

5. 設定逐項講

撳主頁最底嘅「設定」展開。

設定點用
靈敏度 1–9數字越大越易觸發警告。若成日誤報（例如你眼細），調低 1–2 級；若覺得反應遲，調高。行車前先喺安全地方試。
閉眼多久先響警報0.8–2.5 秒，預設 1.2 秒。越短越敏感。
警報音量撳「測試警報」同步聽。手機本身嘅音量都要調高，並要喺行車噪音下仍然清楚。
偵測上限8 / 12 / 15 fps。8 較慳電，15 較準。手機發熱時可以降低。
警報時加語音提示警報時念出「喂！醒呀，醒呀！…」。需要手機有中文語音，見第 11 節。
顯示鏡頭畫面取消剔選即係隱藏，偵測照常。同主頁「隱藏鏡頭畫面」掣一樣。
校準完成後自動隱藏鏡頭畫面見第 3 節。
警報第 2 次起自動播歌「前面有站」見第 8 節。
音樂音量警報同 Buddy 講嘢時音樂會自動收細。
疲倦時自動同我傾偈（Buddy）開啟後，疲倦或警報後 Buddy 會主動開口。需要 API 先有 AI 回應，見第 6 節。

AI 供應商 / API key / 模型名稱 / API 網址見第 6 節。API 網址只有揀「自訂」時出現。
清除所有本機資料刪除設定、API key 同全部駕駛報告，要撳兩次確認。

Android 手機會喺危險警報時震動；iPhone 瀏覽器唔支援網頁震動。

6. AI 聊天 API 設定

Buddy 嘅聊天需要一個 AI 服務。佢唔係必須：冇填 API，警報、偵測、音樂都照用，而 Buddy 會用內置嘅固定句子提示你。

6.1 API Key 係咩？

API Key 係一串密碼式文字，等 AI 服務知道係你喺用。Car Buddy 會用你嘅 Key 向該服務發出聊天請求。Key 只存喺你部手機，詳見私隱政策。

6.2 揀邊個服務

服務特點申請位置
Groq（預設，推薦）反應快，有免費額度；對話延遲低，最適合車上console.groq.com → API Keys
Google Gemini有免費額度，廣東話表現好aistudio.google.com → Get API key
OpenRouter一個 Key 用多個模型，部分模型免費openrouter.ai → Keys
Mistral有免費方案console.mistral.ai
自訂任何兼容 OpenAI /chat/completions 格式嘅服務自行填網址、Key、模型名

免費額度同可用模型會不時改變，以各服務官方網站為準。

6.3 設定步驟（以 Groq 為例）

  1. 用電腦或手機瀏覽器去 console.groq.com 註冊並登入。
  2. 去「API Keys」→「Create API Key」，複製出現嘅文字（通常以 gsk_ 開頭）。Key 只會顯示一次，請即時複製。
  3. 返到 Car Buddy 設定，「AI 服務」揀 Groq，將 Key 貼入「API Key」欄。
  4. 「模型」留空使用預設；如果你想自選，填模型名稱。
  5. 撳主頁「測試語音」確認聽到聲，再撳「同 Buddy 傾偈」。成功會見到 Buddy 回覆並聽到語音。

6.4 出錯時點算

見到原因處理
401 / 403Key 貼錯、過期或被停用重新複製貼上，檢查前後有冇多咗空格
404 / model not found模型已下架或改名清空模型欄；系統會嘗試向服務查詢可用模型並自動改用
429超過免費額度或太頻密等一陣，或轉另一個服務
網絡錯誤手機冇網絡或訊號弱Buddy 會改用內置句子，警報唔受影響
有文字冇聲音手機冇中文語音安裝 Google 粵語語音，見第 11 節

留意：聊天內容（文字）會經網絡傳去你揀嘅 AI 服務；鏡頭畫面唔會。行車時流動數據用量好少，但訊號差時會有延遲。

7. 同 Buddy 傾偈

7.1 Buddy 主動開口

當系統偵測到中度疲倦，或者危險警報之後，Buddy 會用廣東話同你簡短傾偈，保持你清醒。每句約 40 字以內，並一定會提醒你要停車休息。

7.2 你主動叫 Buddy（唔使等系統）

  • 撳掣：Buddy 區塊嘅「同 Buddy 傾偈」。撳咗 Buddy 即刻開口，你可以用語音答佢。
  • 叫名（實驗）：喺設定剔選「語音喚醒（實驗）」後，直接講「Buddy」就會開始。

「叫 Buddy」係實驗功能，有以下限制：

  • 佢要不停聽你講嘢，會多用電同流動數據，聲音會交畀手機嘅語音辨識服務處理（見私隱政策）。
  • Android Chrome 每次重新啟動辨識可能會有「叮」一聲。
  • iPhone Safari 對持續語音辨識支援唔穩定，建議用撳掣方式。
  • 車內噪音大時辨識會唔準。

7.3 音樂同聊天會唔會互相取代？

  • 音樂播放期間，系統唔會自動開口傾偈，避免同歌聲重疊。
  • 但你隨時可以主動撳「同 Buddy 傾偈」或叫「Buddy」。呢個時候音樂會自動暫停俾 Buddy 講，傾完可以撳「繼續播歌」。
  • 危險警報一定優先：警報響起時音樂靜音，警報完先返回。

8. 音樂

  • 可以撳「播放音樂」手動播放。
  • 設定剔選「警報第 2 次起自動播歌」後，同一程出現第 2 次危險警報就會自動播放。
  • 音樂淡入。Buddy 講嘢時音量自動收細。播放時每 4 分鐘會提醒你休息，10 分鐘後自動暫停。
  • 暫停音樂：只有音樂播放時，先會出現「暫停音樂」掣。撳咗只係停歌，偵測繼續運作，直到你撳「停用偵測」。暫停後掣會變成「繼續播歌」。
  • 語音指令：講「播歌」「停歌」亦可以（需要語音辨識已開啟）。
  • 歌曲檔 前面有站.mp3 須與網頁檔放喺同一資料夾。

9. 駕駛偵測報告

每次行程中，只要系統曾經發出過警告或警報，就會自動記錄成一程。沒有警告嘅行程唔會記。

  • 入口：主頁頁尾「駕駛偵測報告」連結。
  • 內容：日期時間、行程長度、警告次數、最長閉眼時間、PERCLOS 峰值，同埋逐項時間線。
  • 「易眼瞓時段」會幫你睇出係行車第幾分鐘、一日中邊個鐘數較常出事，方便你安排休息。
  • 資料只在你部手機，最多 60 程；可喺報告頁清除。

建議：每星期睇一次。如果警報多數出現喺同一時段，就預早喺嗰段時間前安排休息站或換人駕駛。

10. 手機擺放

  • 前置鏡頭要清楚見到你張臉，高度大約同眼睛差不多或略低，避免仰角影到鼻孔。
  • 用穩固嘅車用支架，唔好阻擋視線。
  • 避免陽光直射鏡頭同臉上強烈光影交替（例如行經樹蔭）。
  • 手機要充電：持續用鏡頭同 AI 好耗電。
  • 手機過熱時系統可能降速，請留意散熱。

11. 常見問題

鏡頭畫面黑色或者冇畫面

檢查瀏覽器有冇允許鏡頭；關閉其他正使用鏡頭嘅 App；重新撳開始偵測。

一直誤報

重新校準；降低靈敏度；改善光線；確認眼鏡冇反光。

反應太遲

提高靈敏度；確認校準時冇瞪大眼；確保面部在畫面中央。

Buddy 有字但唔出聲

手機冇中文語音。去 Android「設定 → 一般管理／輔助功能 → 文字轉語音輸出」，安裝或揀「Google 語音」並下載粵語（香港）。

iPhone 上有咩唔同

iPhone 唔支援網頁震動；背景或螢幕鎖定時瀏覽器會暫停偵測，請保持螢幕開住並將頁面放前景；持續語音辨識唔穩定。

打開使用說明／報告後偵測停咗

行駛中開新分頁會令偵測頁變背景，瀏覽器可能減速甚至暫停。請喺停好車時睇呢啲頁面，回到主頁確認偵測仍然運作。

點樣完全清除我嘅資料

設定最底「清除所有本機資料」，或在手機瀏覽器清除本網站嘅儲存資料。
